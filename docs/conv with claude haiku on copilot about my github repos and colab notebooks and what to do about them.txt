🎯 RAGAS for CodexEngine/RAG Evaluation
RAGAS (RAG Assessment) would give you production-grade RAG evaluation, which CodexEngine desperately needs. Here's why:

What RAGAS Measures:
Faithfulness - Does the generated answer stick to retrieved context? (no hallucination)
Answer Relevance - Does the answer actually address the question?
Context Precision - Are the retrieved chunks actually relevant?
Context Recall - Did we retrieve all the relevant context?
Answer Semantic Similarity - Does the generated answer match ground truth semantically?

✅ A "Structured Evaluator" node (but just returns JSON)
