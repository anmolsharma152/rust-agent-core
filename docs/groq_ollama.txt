Groq serves open models like Llama through custom LPU hardware and exposes an OpenAI-compatible chat completions API, which means existing OpenAI client code often works against Groq by only changing the base URL and API key. Ollama runs open-weight models locally and, in recent versions, also exposes an OpenAI-compatible endpoint at /v1/chat/completions, which makes it a natural drop-in fallback when a cloud API is unavailable, rate-limited, or the machine has no internet access.
